2. 💡 **Planner Deliberation**: Generates a structured task breakdown DAG using reasoning models[span_22](start_span)[span_22](end_span).
3. 🛠️ **Agent Execution**: Dispatcher routes sub-tasks to designated specialized models[span_23](start_span)[span_23](end_span).

5. ⏪ **Auto-Rollback / Outer-Loop**: Reverts workspace changes via Git snapshot if verification fails[span_25](start_span)[span_25](end_span).
