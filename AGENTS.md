# Apex Multi-Agent Orchestration Directives

This file acts as the source of truth for the `OuterVerificationLoop`. The Thinking Engine and CLI Scaffolder must strictly adhere to these boundaries.

## Security & Execution Boundaries
- Rule: Agents MUST NOT execute raw `eval()` or `exec()` without invoking the `REPLSandbox`.
- Rule: eBPF monitoring MUST remain active for all spawned subprocesses in production.
- Rule: Hardcoded secrets or private keys are strictly forbidden in generated AST patches.

## Web3 & Decentralized Finance
- Rule: All Monad RPC interactions MUST invoke `estimate_transaction` before state-changing broadcasts.
- Rule: Contract interactions must reference the `MonYield-Back-Donation` canonical ABI definitions.

## Workflow & Git Ops
- Rule: Commits generated by FixFlow must follow Conventional Commits formatting.
- Rule: Branching models must adhere to strict GitFlow for release management.
